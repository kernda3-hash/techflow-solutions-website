**# What would happen if you pushed code to a different branch (not main)?**

The workflow would not automatically run just because code was pushed to a different branch, since the push trigger only includes `main`. A pull request targeting `main` would still trigger the workflow. The deployment job only deploys when the event is a push to `main`, so changes on other branches would not be deployed to GitHub Pages. Using separate branches allows developers to work on changes and test them before merging into the main branch. This helps prevent unfinished or untested changes from being published to the live website.
